# SPORT Web · WEB007 · INTEROP002 AUTO

## Objectif
Supprimer la dernière différence ergonomique entre le Web et les deux clients Android :
une modification utilisateur doit se synchroniser sans bouton de validation.

## Comportement
- titre personnalisé : sauvegarde automatique 800 ms après la dernière frappe ;
- note personnelle : même autosauvegarde ;
- changement de champ / navigation : vidage immédiat du brouillon en attente ;
- choix d'un nouveau repère : ajout immédiat ;
- boutons + / − des repères : synchronisation immédiate, comme en WEB006 ;
- événements Firestore `changes` inchangés pour téléphone et tablette ;
- écoute `onSnapshot` inchangée pour Android → Web.

## Robustesse
Les écritures texte sont mises dans une file asynchrone sérialisée afin d'éviter qu'une ancienne
requête termine après une requête plus récente et rétablisse une ancienne valeur.

Un brouillon Web en cours n'est pas écrasé visuellement par un événement temps réel arrivant
pendant la frappe. En cas de modifications véritablement simultanées sur plusieurs plateformes,
la dernière écriture effectivement envoyée reste la valeur finale.

## Périmètre
Aucune nouvelle version Android n'est requise.
WEB005 CARTO+, Comfortaa et le correctif z-index sont conservés.
