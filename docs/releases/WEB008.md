# SPORT Web · WEB008 · EDITION002

## Objectif
Approcher la parité de modification d’une activité entre le Web, le téléphone et la tablette,
tout en conservant l’autosynchronisation de WEB007.

## Champs éditables sur les trois plateformes
- titre personnalisé ;
- description ;
- note personnelle ;
- matériel utilisé ;
- ressenti, de 1 à 5 ;
- difficulté, de 1 à 10 ;
- confidentialité locale : privée, non répertoriée ou publique ;
- repères personnels et leur compteur.

## Synchronisation
- texte : autosauvegarde après 800 ms ;
- sélecteurs et repères : envoi immédiat ;
- chaque écriture Web met à jour le document activité et publie un événement `changes` ;
- Android applique les colonnes reçues dans SQLite avec sa garde anti-boucle Firebase ;
- le Web écoute les événements Android avec `onSnapshot` et rafraîchit la fiche ouverte.

## Matériel
L’activité Android stocke l’affectation par nom d’affichage. WEB008 utilise donc le même nom
d’affichage et force `equipment_manual=1`, exactement comme un choix manuel dans SPORT Android.

## Limites volontaires
WEB008 ne modifie pas encore :
- sport / sous-sport ;
- suppression d’activité ;
- fichiers FIT ou points GPS ;
- création / modification du catalogue de matériel lui-même.

Ces opérations auront des garde-fous dédiés plutôt que d’être ajoutées à l’édition courante.
