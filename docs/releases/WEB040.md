# WEB040 · WEBSTRAVA001

## Strava devient une source d'entrée SPORT Web

### Interface
- Nouvelle rubrique `Plus > Strava`.
- Connexion OAuth Strava.
- Période : 7 / 30 / 90 / 365 jours.
- Aperçu avant import.
- Détection des doublons :
  - `strava_activity_id` identique ;
  - date ±2 minutes + distance ±2 % / 100 m.
- Les doublons sont décochés par défaut.
- Import sélectionné dans `activities`.
- Streams Strava publiés dans `activity_routes` :
  `time`, `distance`, `latlng`, `altitude`, `heartrate`, `velocity_smooth`, `cadence`.
- Les séries détaillées rendent progressivement disponibles les courbes allure/FC et l'analyse km de WEB034.
- Aucune activité Strava n'est modifiée.

### Backend sécurisé
Le dossier `functions/` contient la Firebase Function `stravaBridge`.

Le `STRAVA_CLIENT_SECRET` n'est jamais livré au navigateur ni stocké dans GitHub.
Le backend :
- vérifie le Firebase ID token SPORT ;
- gère OAuth Strava ;
- stocke access/refresh tokens côté serveur ;
- rafraîchit les tokens expirés ;
- lit les activités et streams Strava ;
- permet la déconnexion.

Scopes demandés : `read,activity:read_all`.

### Déploiement
WEB040 publie GitHub Pages normalement. Le backend Functions nécessite une configuration Strava/Firebase séparée avant le premier OAuth.

Référence Strava actuelle :
- OAuth2 et secrets côté serveur ;
- `/athlete/activities` pour la liste ;
- `/activities/{id}` pour le détail ;
- `/activities/{id}/streams` pour les streams.
