# WEB035 · WEBIMPORT001

## Import FIT manuel depuis SPORT Web

Première brique du basculement du point d'entrée Android vers Web.

### Fonctionnalités
- `Plus > Import`.
- Glisser-déposer ou sélection multiple de fichiers `.fit`.
- Décodage FIT directement dans le navigateur :
  - sport / sous-sport interne ;
  - date et durée ;
  - distance ;
  - D+ / D− ;
  - calories ;
  - FC moyenne / maximale ;
  - vitesse ;
  - records GPS, altitude, distance, temps, FC et vitesse.
- Prévisualisation avant toute écriture.
- Empreinte SHA-256 du fichier.
- Détection de doublon :
  - SHA identique ;
  - date à ±2 min + distance à ±2 % / 100 m.
- Les doublons sont décochés par défaut mais restent importables après confirmation.
- Création de l'activité dans `activities`.
- Publication d'un aperçu GPS compact dans `activity_routes` (maximum 800 points).
- Conservation optionnelle, activée par défaut, du FIT original dans IndexedDB (`sport_web_import_archive_v1`).

### Sécurité des fichiers
WEBIMPORT001 ne stocke pas le binaire FIT dans Firestore. Le coffre IndexedDB est une copie locale liée au navigateur et ne remplace pas une vraie sauvegarde cloud. L'archivage cloud sera traité séparément par WEBFILES001 / WEBDRIVE001.

### Compatibilité
- Aucun changement Android.
- Aucun nouveau secret OAuth.
- Le modèle Firestore `activities` / `activity_routes` existant est réutilisé.
