# SPORT Web · WEB003

## Objectif
Faire de la consultation d'une activité une vraie vue Web complète, sans quitter le catalogue et sans introduire d'écriture Firestore.

## Fonctionnalités
- conserve le répertoire avancé de WEB002 ;
- chargement Firestore par lots de 250 ;
- bouton de chargement intégral ;
- recherche et filtres Sport / Année / Matériel / Repère / Source / Distance / D+ ;
- tris date, distance, D+ et durée ;
- clic sur une activité pour ouvrir une fiche complète ;
- navigation activité précédente / suivante dans le résultat filtré ;
- retour au répertoire en conservant la position de défilement ;
- synthèse : date, sport, distance, durées, D+, D-, calories, points GPS ;
- performance : FC, cadence, vitesse moyenne et allure calculée ;
- matériel, repères, occurrences et source MANUAL/AUTO ;
- titre, description et note personnelle ;
- records liés à l'activité ;
- source/import, fichier FIT, fabricant, produit, segmentation et versions ;
- panneau repliable exposant toutes les clés du document Firestore.

## Sécurité
WEB003 reste strictement en lecture seule.
Le workflow refuse la publication si une API Firestore d'écriture standard est détectée dans `web/app.js`.

## Limite volontaire
La cartographie n'est pas encore affichée dans WEB003. Le bootstrap Web actuel matérialise le résumé d'activité et le nombre de points GPS, mais pas la collection `activity_points`. La carte fera l'objet d'une étape dédiée quand le transport des points aura été défini proprement.
