# SPORT Web · WEB009 · MATÉRIEL001

## Priorité
Poursuivre la parité des trois clients SPORT : Web, téléphone et tablette.

## Nouveau gestionnaire matériel
WEB009 ajoute au catalogue Web une rubrique de gestion du matériel synchronisée avec Firestore :
- création d’un nouveau matériel ;
- modification automatique des champs de la fiche ;
- statut Actif / En réserve / Retiré-archivé ;
- réactivation ;
- catégorie, nom personnalisé, marque, modèle et numéro d’exemplaire ;
- date et prix d’achat ;
- notes ;
- seuils distance et durée ;
- affichage des compteurs d’usage.

## Compatibilité Android
Les catégories envoyées sont les valeurs exactes de `EquipmentCategory` :
`SHOES`, `BIKE`, `HOME_TRAINER`, `HEADLAMP`, `BACKPACK`, `POLES`, `WATCH`,
`HEART_RATE_SENSOR`, `OTHER`.

Les statuts envoyés sont les valeurs exactes de `EquipmentStatus` :
`ACTIVE`, `STORED`, `RETIRED`.

Les événements utilisent la table `equipment`, déjà comprise par le récepteur Firebase Android.
Aucune nouvelle APK n’est requise pour WEB009.

## Création et bootstrap
Une création ajoute un document `equipment` et incrémente atomiquement :
- `meta/state.equipmentCount` ;
- `meta/state.expectedDocuments`.

La reconstruction d’un futur appareil neuf reste donc cohérente.

## Renommage sûr
Les activités SPORT sont reliées au matériel par `equipment_name`.
Si le nom d’affichage d’un matériel change, WEB009 met à jour dans le même batch :
- la fiche matériel ;
- toutes les activités Firestore utilisant l’ancien nom ;
- un événement `changes` pour chaque activité afin que téléphone et tablette suivent.

Pour rester sous la limite Firestore de 500 écritures par batch et garder une propagation Android
prévisible, un renommage Web est bloqué au-delà de 180 activités associées. Dans ce cas, aucune
écriture n’est effectuée et la fiche reste cohérente.

## Suppression
WEB009 ne supprime pas physiquement les fiches matériel. `RETIRED` sert d’archivage réversible,
ce qui protège l’historique des activités.

## Héritage
WEB008 EDITION002, l’autosynchronisation, Comfortaa, CARTO+ et le correctif z-index sont conservés.
