# SPORT Web · WEB015 · DASHBOARD002

## Objectif
Faire du tableau de bord Web un véritable outil d'analyse sans remettre en cause la priorité du projet : les données restent celles du même compte Firestore et toute donnée modifiable demeure interopérable avec téléphone et tablette.

## Nouveautés
- comparaison de la période courante avec la période précédente au même stade ;
- graphique interactif Distance / D+ / Temps ;
- clic sur une barre pour charger et filtrer les activités correspondantes ;
- tendances 30, 90 et 365 jours avec moyenne kilométrique hebdomadaire ;
- progression vers les objectifs annuels synchronisés par WEB013 ;
- répartition Course à pied / Vélo ;
- matériel réellement utilisé sur la période sélectionnée ;
- dernières activités ;
- records SPORT accessibles depuis le tableau de bord.

## Périodes
- Semaine : barres quotidiennes ;
- Mois : barres quotidiennes ;
- Année : barres mensuelles ;
- Total : métriques via agrégations Firestore et graphique limité aux 12 derniers mois afin d'éviter de télécharger tout l'historique.

## Interopérabilité et sécurité
WEB015 est une évolution analytique. Elle conserve intégralement :
- l'édition tridirectionnelle ;
- WEB011 CORBEILLE001 ;
- WEB013 objectifs + poids ;
- WEB014 historique / conflits ;
- CARTO+, Comfortaa et le correctif z-index.

Aucune nouvelle APK Android n'est requise.
