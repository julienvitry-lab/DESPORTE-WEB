# WEB044 · WEBSPLIT003

- Découpe automatique prioritaire : aucun curseur lorsque SPORT détecte une rupture.
- GAP > 15 minutes = coupure automatique.
- Changement sport / sous-sport = coupure automatique.
- Changement de matériel = coupure automatique si la source fournit le matériel par point ou par session.
- Plusieurs ruptures produisent 2 à N activités.
- Le curseur manuel reste uniquement comme secours lorsqu’aucune rupture automatique n’est détectée.
- La source est placée dans la corbeille après découpe automatique afin d’éviter le double comptage.
- Les futurs imports Strava restent découpés côté serveur sur GAP > 15 minutes, même navigateur fermé.
