# SPORT Web · WEB004 CARTO

## Objectif
Afficher un tracé GPS et un profil altimétrique dans la fiche activité WEB003 sans charger les millions de points bruts dans Firestore.

## Source
WEB004 lit un document compact par activité :

`sport_users/{uid}/activity_routes/{activityId}`

Ces documents sont produits par SPORT Android v215 / CARTOWEB001 et contiennent au maximum 280 points d'aperçu.

## Fonctionnalités
- carte Leaflet avec fond OpenStreetMap ;
- tracé GPS complet à l'échelle de l'activité ;
- marqueurs départ et arrivée ;
- cadrage automatique du parcours ;
- profil altimétrique SVG sans librairie graphique supplémentaire ;
- distance et altitude au survol du profil ;
- curseur du profil synchronisé avec un marqueur sur la carte ;
- gestion explicite des activités sans GPS ou dont le tracé n'a pas encore été publié ;
- conservation de tout WEB003 : catalogue avancé, fiche complète, navigation précédente/suivante.

## Lecture seule
WEB004 n'utilise aucune API Firestore d'écriture. La publication des tracés est assurée uniquement par SPORT Android.

## Cartographie
Le fond de carte utilise Leaflet 1.9.4 et les tuiles OpenStreetMap. L'attribution OpenStreetMap reste visible sur la carte.
