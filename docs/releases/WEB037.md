# WEB037 · WEBSPLIT001

## Découpe non destructive d'une activité

- Bouton `✂ Découper` dans la fiche activité.
- Disponible lorsque `activity_routes` contient une chronologie point-par-point exploitable.
- Adapté immédiatement aux FIT importés par WEB035, qui publient `time_ms`.
- Profil altimétrique de découpe avec curseur de coupure.
- Prévisualisation en temps réel des deux parties :
  - distance ;
  - durée ;
  - D+ / D− ;
  - allure ;
  - FC moyenne.
- Création de deux activités dérivées dans `activities`.
- Création de deux tracés dérivés dans `activity_routes`.
- Relation enregistrée :
  - enfants : `split_parent_activity_id`, `split_part` ;
  - source : `split_status=SOURCE`, `split_children_ids`.
- L'activité source n'est jamais supprimée.
- Le FIT original archivé par WEB035 n'est jamais modifié.
- Les calories de la source, lorsqu'elles existent, sont réparties proportionnellement au temps et marquées `PROPORTIONAL_TIME`.
- WEB037 ne fabrique pas encore deux nouveaux fichiers FIT binaires. Cette partie relève du futur coffre de fichiers / encodeur.
- Aucun changement Android.
