# WEB020 · WEBCARTO005

Analyse kilomètre par kilomètre du tracé Web.

- découpage automatique en kilomètres, avec dernier tronçon adapté ;
- D+, D−, altitude min/max, pente moyenne et pente maximale par tronçon ;
- clic sur un kilomètre : zoom carte + surbrillance du profil ;
- bouton « Tout le tracé » pour revenir à la vue globale ;
- aucun changement du modèle Firebase ni d'Android.

Note : les documents `activity_routes` actuels ne publient pas une chronologie point par point fiable.
WEB020 n'invente donc ni temps ni allure par kilomètre ; ces métriques seront ajoutées lorsqu'une
chronologie de route sera publiée.
