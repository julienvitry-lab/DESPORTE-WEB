# WEB046 · WEBACTIVITY002

Deuxième passe de simplification de l'onglet Activités :
- suppression du grand titre Activités dans l'onglet déjà sélectionné ;
- un seul statut d'interopérabilité, compact, dans le topbar juste avant Firebase ;
- suppression de l'en-tête WEB031 / Répertoire / compteur ;
- commandes de chargement déplacées en bas du répertoire ;
- icônes course/vélo SVG agrandies et centrées verticalement ;
- date + heure présentées comme une donnée « Départ », au même format visuel que Distance/D+/Durée ;
- barre de navigation ET résumé activité ancrés ensemble ;
- résumé détail conservé sur deux lignes : statistiques puis matériel + repères.

Aucune modification Firestore, Strava ou WEBSPLIT.
