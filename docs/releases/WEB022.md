# WEB022 · WEBCARTO007

## Comparaison de deux activités

- choix d’une seconde activité depuis le détail ;
- superposition de sa trace en bleu pointillé sur la carte ;
- superposition de son profil altimétrique ;
- affichage des écarts globaux de distance, D+ et durée ;
- cadrage automatique sur les deux traces ;
- retrait instantané de la comparaison ;
- conservation de WEBCARTO002 à WEBCARTO006.

Les activity_routes actuels ne contiennent pas encore une chronologie point par point fiable. WEB022 n’invente donc pas de « temps gagné/perdu » local : ce calcul sera activé quand les timestamps de route seront publiés.
