# WEB036 · WEBMANUAL001

## Ajout manuel d'une activité depuis SPORT Web

- Nouvelle rubrique `Plus > Ajout manuel`.
- Création d'une activité sans fichier FIT.
- Champs :
  - sport ;
  - date / heure ;
  - distance ;
  - durée ;
  - D+ / D− ;
  - FC moyenne / max ;
  - calories ;
  - matériel actif compatible avec le sport ;
  - titre ;
  - notes ;
  - repères avec occurrences multiples.
- Les repères utilisent la même logique de compteur que WEB033.
- Détection de doublon probable avant création.
- Avertissement explicite si calories absentes.
- Création dans la collection `activities` via le mécanisme de mutation Web déjà existant.
- Aucune trace GPS n'est inventée : `gps_point_count = 0` et `record_count = 0`.
- Une trace pourra être associée ultérieurement.
- Aucun changement Android.
