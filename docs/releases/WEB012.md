# SPORT Web · WEB012 · DASHBOARD001

## Objectif
Ajouter un véritable tableau de bord Web tout en conservant les fonctions métier et l'interopérabilité validées jusqu'à WEB010.

## Tableau de bord
- sélecteur Course à pied / Vélo ;
- périodes Semaine / Mois / Année / Total ;
- activités, distance, durée et D+ ;
- matériel actif avec cumuls ;
- cinq dernières activités ouvrables directement.

Les périodes courtes sont calculées à partir d'une requête Firestore bornée par date. Le total utilise les agrégations serveur Firestore pour éviter de télécharger des milliers d'activités dans le navigateur.

## Héritage
WEB010 repères/records, WEB009 matériel, WEB008 édition activité, autosynchronisation, Comfortaa, CARTO+ et z-index sont conservés.
