# WEB074 · FITCLOUD001 / HISTORICAL_IMPORT001

## Fonction Android retrouvée

Le pipeline Android repose sur :
- `ImportRuleSet` : seuil de pause par défaut = 15 minutes ;
- `ImportPipeline` : frontière sur changement de sport, sous-sport ou pause >= seuil ;
- `FitSegmentFactory` : reconstruction des segments ;
- `FitFileNaming` : nom canonique `AAAA_MM_JJ_HH_MM_SS_C.fit` ;
- `StravaStreamActivityFactory` : reconstruction depuis les streams Strava ;
- `FitDestinationStore` + `CanonicalFitWriter` : production du FIT canonique.

Point important : pour Strava, l'app ne télécharge pas le FIT original depuis Strava. Elle télécharge les métadonnées/streams puis reconstruit un FIT canonique SPORT.

## WEB074

Première brique de centralisation Web :
- stockage privé dans Firebase Storage ;
- manifeste `sport_users/{uid}/activity_files/{sha256}` dans Firestore ;
- déduplication par SHA-256 ;
- migration historique de lots ou dossiers FIT ;
- rapprochement avec les activités déjà existantes ;
- garantie du mode historique : aucune écriture/création dans `activities` ;
- téléchargement et suppression distante des fichiers.
