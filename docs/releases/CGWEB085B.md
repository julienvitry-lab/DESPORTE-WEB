# CGWEB085B · FULLARCHIVE001

`Plus → Fichiers → Export période` propose :
- Mois
- Année
- Tout

Le mode Tout contient :
- activities.csv
- activities.json
- manifest.json
- README.txt
- matériel
- mappings matériel
- repères
- références repères
- liens activité/repères
- records
- historique SAFEEDIT
- meta/state
- activity_routes
- FIT actifs/préférés

Option : inclure toutes les versions FIT.

Les versions sont rangées par activité/version dans `FIT_VERSIONS/`.
Le nom canonique du FIT lui-même reste inchangé.
