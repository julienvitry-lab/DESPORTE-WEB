# WEB041 · WEBSTRAVA002

## Synchronisation Strava automatique

WEBSTRAVA002 supprime le besoin de charger puis importer manuellement les nouvelles activités Strava lorsque SPORT Web est ouvert.

### Déclenchements automatiques
- après connexion Firebase et chargement initial de SPORT Web ;
- après une connexion OAuth Strava réussie ;
- au retour de la connexion réseau ;
- au retour sur l’onglet / la fenêtre ;
- toutes les 5 minutes pendant que SPORT Web reste ouvert.

### Rattrapage
- première synchronisation automatique : 30 derniers jours ;
- synchronisations suivantes : reprise depuis le dernier succès avec 48 h de recouvrement ;
- la date du dernier contrôle réussi est conservée par utilisateur dans le stockage local du navigateur.

### Anti-doublon
Avant tout import automatique :
1. contrôle des activités déjà chargées dans SPORT ;
2. contrôle exact Firestore de `strava_activity_id` ;
3. conservation du rapprochement probable WEBSTRAVA001 (date ±2 min et distance ±2 % / 100 m).

Une activité déjà connue n’est pas réimportée. Une activité nouvelle est récupérée avec son détail et ses streams puis publiée dans `activities`, `activity_routes` et `/changes` via le protocole Web existant.

### Import manuel conservé
Les boutons de contrôle et d’import restent disponibles pour audit ou reprise manuelle.

### Portée
Cette version automatise Strava → SPORT tant que SPORT Web peut s’exécuter dans le navigateur. Elle ne prétend pas synchroniser lorsque tous les navigateurs sont fermés ; ce cas nécessite un webhook ou une tâche serveur dédiée.
