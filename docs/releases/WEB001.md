# SPORT Web — WEB001

## Objectif
Créer le premier client navigateur de SPORT, directement connecté au même Firestore que les appareils Android.

## Périmètre WEB001
- hébergement statique GitHub Pages ;
- authentification Google via Firebase Authentication ;
- accès au chemin `sport_users/{uid}` du compte connecté ;
- lecture de `meta/state` ;
- compteurs activités, matériels, repères, liens et records ;
- répertoire paginé des activités, 100 par 100 ;
- recherche locale dans les activités déjà chargées ;
- filtres sport et année ;
- détail d'une activité ;
- affichage de ses repères restaurés depuis `activity_landmarks` ;
- affichage des records ;
- interface responsive téléphone / tablette / ordinateur.

## Sécurité
WEB001 est strictement en lecture seule :
- aucun `setDoc` ;
- aucun `addDoc` ;
- aucun `updateDoc` ;
- aucun `deleteDoc` ;
- aucun batch d'écriture ;
- aucune réinitialisation Firestore.

Le workflow GitHub refuse WEB001 si une API d'écriture Firestore est introduite dans `web/app.js`.

## Hébergement
URL attendue après activation de GitHub Pages :
`https://julienvitry-lab.github.io/DESPORTE/`

Pour la connexion Google, le domaine `julienvitry-lab.github.io` doit être présent dans Firebase Authentication → Settings → Authorized domains.

## Schéma lu
`/sport_users/{uid}/meta/state`
`/sport_users/{uid}/activities`
`/sport_users/{uid}/landmarks`
`/sport_users/{uid}/activity_landmarks`
`/sport_users/{uid}/records`

Les points GPS/FC détaillés et les fichiers FIT ne font pas encore partie de WEB001.
