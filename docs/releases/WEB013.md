# SPORT Web · WEB013 · PERSONAL001

WEB013 rend interopérables les objectifs SPORT et le suivi du poids.

- objectifs pour Course à pied, Vélo, Natation, Marche, Randonnée et Autres sports ;
- distance/D+/durée annuels, course cible et préparation 90 jours ;
- progression annuelle calculée depuis les activités Firestore ;
- saisie du poids par date, historique et évolution ;
- autosynchronisation Web -> téléphone/tablette via `changes` ;
- réception temps réel Android -> Web.

Une APK Android compagnon WEB013SYNC001 est nécessaire pour connecter les stores locaux `SportGoalStore` et `journal001.db` à la passerelle Firebase. Le tableau de bord WEB012 et tout le socle WEB010 sont conservés.
