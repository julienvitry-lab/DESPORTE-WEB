# SPORT Web · WEB010 · MÉTIER001

## Objectif
Continuer la parité métier Web ⇄ téléphone ⇄ tablette après WEB009.

## REPÈRE013
Le catalogue des repères devient administrable depuis le Web :
- création d’un nouveau repère ;
- modification automatique du libellé ;
- modification de l’ordre ;
- type Trajet / Ascension ;
- comptage des activités et occurrences ;
- affichage de la présence d’une référence GPS ;
- suppression d’un repère personnalisé uniquement lorsqu’il n’est plus utilisé.

Le code du repère reste fixe après création : il est la clé primaire SQLite et la clé des
associations `activity_landmarks`.

Les dix codes SPORT historiques `B,Q,C,M,R,Y,V,A,X,F` sont protégés contre la suppression,
car Android les réensemence automatiquement.

Si une référence GPS existe, WEB010 bloque un changement Trajet ⇄ Ascension pour ne pas rendre
la référence `ROUTE` / sommet incohérente.

Une création incrémente `landmarkCount` et `expectedDocuments`.
Une suppression personnalisée autorisée les décrémente.

## Références de repères
WEB010 charge et écoute aussi `landmark_references` / `personal_landmark_references`.
Les références créées depuis Android sont donc visibles en temps réel dans le gestionnaire Web.

## RECORDS001
Les records SPORT sont dérivés des activités. WEB010 ne permet donc pas de saisir arbitrairement
un faux record.

Le bouton « Recalculer les records » recherche directement dans Firestore :
- la distance maximale (`distance_m`) ;
- la durée active maximale (`timer_time_ms`) ;
- le D+ maximal (`ascent_m`).

Les trois lignes `records` sont ensuite mises à jour avec des événements `changes`, ce qui propage
le résultat vers téléphone et tablette. Si un record devait être créé ou retiré, `recordCount` et
`expectedDocuments` sont ajustés atomiquement.

## Héritage
WEB009 MATÉRIEL001, WEB008 EDITION002, l’autosynchronisation, Comfortaa, CARTO+ et le correctif
z-index restent actifs.

Aucune nouvelle APK Android n’est nécessaire : les tables `personal_landmarks`,
`personal_landmark_references` et `records` sont déjà comprises par le récepteur Firebase Android.
