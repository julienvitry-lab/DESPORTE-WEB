# SPORT Web · WEB005 CARTO+

## Objectif
Polir WEB004 pour aligner visuellement SPORT Web avec l'application Android et renforcer l'interaction carte/profil.

## Interface
- police Comfortaa sur toute l'interface Web, comme SPORT Android ;
- correction du z-index : Leaflet est enfermé dans son propre contexte d'empilement et ne recouvre plus le bandeau SPORT ni la navigation sticky ;
- responsive conservé sur ordinateur, tablette et téléphone.

## CARTO+
- choix OpenStreetMap / OpenTopoMap ;
- plein écran de la carte avec recalcul Leaflet au changement de mode ;
- marqueurs Départ / Arrivée plus lisibles ;
- statistiques du tracé : distance, D+ du profil compact, altitude min/max, nombre de points ;
- survol du profil : km, altitude, D+ cumulé et marqueur synchronisé sur la carte ;
- survol de la carte : synchronisation inverse vers le profil altimétrique ;
- tooltip cartographique synchronisé.

## Sécurité
WEB005 reste strictement en lecture seule. Il lit toujours les documents compacts `activity_routes` produits par CARTOWEB001.
