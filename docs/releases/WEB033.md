# WEB033 · WEBUX003

## Fiche activité encore plus compacte

- En-tête sur une seule ligne horizontale :
  sport, date/heure, distance, durée, D+, allure/vitesse et FC moyenne.
- Suppression définitive de la mention visible `Sous-sport`.
- Calories retirées de la barre principale :
  une alerte visible signale désormais explicitement une valeur manquante.
- Matériel :
  - uniquement statut `ACTIVE` dans la liste ;
  - filtrage par famille de sport (course → chaussures, vélo → vélo/home trainer, etc.) ;
  - une affectation historique inactive reste visible sans être proposée comme nouveau choix.
- Repères rapides transformés en compteurs :
  - clic sur le code = +1 occurrence ;
  - bouton `−` = retrait d'une occurrence ;
  - affichage `R ×2`, `B ×3`, etc.
- Suppression visuelle de l'encart Notes / informations personnelles.
- Bouton discret `Données` dans la barre supérieure pour afficher les données techniques à la demande.
- Les rectangles Allure/Vitesse et FC moyenne deviennent cliquables.
- Le Web affiche une vraie courbe uniquement si `activity_routes` contient les séries point-par-point
  (timestamps / vitesse / fréquence cardiaque). Sinon il l'indique explicitement et ne fabrique pas de courbe.
- Aucun changement de schéma Firebase ni Android.
