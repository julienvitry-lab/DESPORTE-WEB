# WEB055-FIX5 · GOAL006 / REGULARITY005 / COMPARE005

## Objectifs
- Corrige le calcul du nombre de jours de l'année : 365/366 au lieu de 31.
- La cible théorique est exactement la fraction de l'année écoulée.
- Rouge = cible théorique cumulée ; vert = réalisé ; or = avance.
- Trois indicateurs conservés : reste, rythme hebdo théorique, rythme quotidien théorique.

## Régularité
- Mode simple par défaut : Distance ou D+ via menu déroulant.
- Bouton « + 2e critère » pour activer explicitement une combinaison ET/OU.
- Le deuxième critère est automatiquement l'autre métrique.
- Histogramme annuel et survol conservés.

## Comparaison
- Titre raccourci à « Comparaison ».
- Année antérieure toujours sélectionnable.
- Déplacement du pointeur sur le graphique : date, valeurs et écart évoluent en direct.
