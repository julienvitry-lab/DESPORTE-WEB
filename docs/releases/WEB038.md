# WEB038 · WEBFILES001

## Coffre de fichiers SPORT Web

- Nouvelle rubrique `Plus > Fichiers`.
- Inventaire des FIT originaux archivés par WEB035 dans IndexedDB.
- Affiche :
  - nom du fichier ;
  - taille ;
  - date ;
  - SHA-256 ;
  - nombre d'activités liées.
- Recherche et filtres :
  - tous ;
  - originaux FIT ;
  - dérivés / découpes ;
  - fichiers non liés.
- Téléchargement d'un original FIT depuis le coffre local.
- Vérification d'intégrité SHA-256 à la demande.
- Suppression possible de la copie locale uniquement, avec confirmation :
  aucune activité Firestore n'est supprimée.
- Les activités créées par WEB037 sont recensées comme dérivées :
  leur relation avec l'activité source est visible.
- Tant qu'un encodeur FIT dérivé n'existe pas, le coffre indique explicitement `FIT non généré`.
- Résumé : nombre d'originaux, taille locale, activités liées, dérivés sans FIT.
- Aucun fichier binaire n'est envoyé à Firestore.
- Aucun changement Android.
- Google Drive n'est pas encore activé : il viendra dans WEBDRIVE001.
