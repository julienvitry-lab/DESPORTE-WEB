# WEB028 · WEBREPERES002

## Valider une ascension reconnue comme repère officiel

- Hérite de WEB025 / WEBREPERES001 pour la reconnaissance géographique des ascensions récurrentes.
- Ajoute un bouton « Valider comme repère » sur chaque montée analysée.
- La création reste entièrement manuelle :
  - choix du nom ;
  - choix du code métier ;
  - confirmation finale avant écriture.
- Crée un vrai `personal_landmarks` de type `Ascension` avec le schéma Firebase déjà existant.
- Associe toujours le repère à l'activité courante.
- Lorsque d'autres passages sont reconnus, propose explicitement de les associer aussi à ce repère.
- Les associations utilisent `activity_landmarks` et restent donc compatibles Web / téléphone / tablette.
- Aucun repère n'est créé automatiquement par la reconnaissance géographique.
- Aucun nouveau format Firebase, aucune nouvelle collection et aucun changement Android.
